## 第 9 章　常用 Skills 實戰

最常用的 Skill 可分為：

- **導覽：** 找入口檔、相關測試與資料流，先不修改。
- **除錯：** 重現錯誤、提出假設、加入或更新測試、最小修正。
- **重構：** 列出不變條件與預期 diff，逐步修改並測試。
- **審查：** 依正確性、安全性、測試與可維護性分類問題。
- **Git 摘要：** 根據已審查的 diff 產生提交說明，不自行提交。
- **文件：** 從程式與測試萃取 README 或 API 說明，標出無法驗證的敘述。

把每個 Skill 的輸入、允許工具、成功條件與失敗處理寫清楚，能減少看似流暢但不可驗證的回覆。
