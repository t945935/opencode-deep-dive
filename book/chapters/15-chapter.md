# 第 15 章　替換終端機 UI

## 本章目標

理解 TUI 只是客戶端之一，並規劃 Web、桌面、遠端或非互動介面需要的事件、權限與取消機制。

## 15.1 UI 與核心分離

介面負責顯示訊息、工具確認、Session 列表、串流狀態與錯誤；核心服務負責模型、工具、權限與持久化。不要在畫面元件內直接執行 Shell，也不要以「隱藏按鈕」繞過權限確認。

## 15.2 必備互動

替代 UI 至少要能顯示目前 Session、模型、正在執行的工具、工具輸入摘要、取消按鈕與最終結果。工具執行時間較長時，UI 應顯示進度與逾時，而不是讓使用者以為程式掛起。

## 15.3 遠端與非互動執行

`opencode run` 適合腳本，但腳本必須明確設定工作目錄、輸入、輸出與退出碼。Web 或遠端服務則需增加身分驗證、租戶隔離、CORS、請求取消與日誌遮罩。不可把本機 TUI 的信任模型直接搬到網路服務。

## 練習與小結

設計一個最小 Web Client 的狀態圖：Idle、Waiting、Tool Approval、Running、Completed、Failed、Cancelled。為每個轉移定義觸發事件與可見訊息。
