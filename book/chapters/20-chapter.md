## 第 20 章　OpenCode 與主流工具比較

OpenCode 適合偏好終端機、需要多 Provider 選擇、希望以 MCP／Plugin／SDK 客製整合的開發者。Claude Code 與 Aider 也適合終端機工作流；Cursor、Windsurf 等 IDE 工具則適合需要圖形化編輯、補全與內建視覺操作的使用者；GitHub Copilot 適合已深度使用 GitHub 生態的團隊。

沒有工具能免除工程判斷。若需求只是 IDE 補全，建立 Extension-first 平台通常過度複雜；若要把代理嵌入產品、控制 Provider 與工具生命週期，單一 IDE Agent 則可能不夠。以工作流、治理與整合需求選擇，而非只比較模型名稱。
